# Contributing

Thank you for considering a contribution to HCC Analytics BD.

## Suitable contributions

- Improve field definitions, calculations or documentation
- Add reusable compensation, benefits, attendance, payroll or compliance analyses
- Correct a data-quality or consistency issue
- Add Excel, Power BI, Looker Studio, SQL or Python examples
- Improve accessibility or chart interpretation
- Add tests without introducing real personal or organisational data

## Contribution process

1. Fork the repository.
2. Create a focused feature branch.
3. Make and document your changes.
4. Run the relevant validation or build checks.
5. Do not commit credentials, real employee information or confidential data.
6. Open a pull request explaining the change and its analytical value.

## Data policy

All contributed records must remain synthetic. Contributions containing real
personal, medical, payroll, applicant, banking, tax or confidential
organisational data will not be accepted.
